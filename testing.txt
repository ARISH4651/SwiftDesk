# Design Testing Checklist
1. Ticket Creation
Valid ticket is accepted
Invalid JSON is rejected
Missing required fields return proper validation error
Ticket ID is generated
Status defaults to Open

2. AI Classification
AI verifies customer priority
AI verifies customer category
AI returns confidence score
AI returns reasoning
AI detects language
AI normalizes non-English tickets
Original values are preserved
Resolved values are stored

3. Hidden Trap Tests
1.Wrong Priority
Customer gives incorrect priority
AI changes it correctly
Audit log records the correction
2.Missing Priority
Null priority accepted
AI infers priority
Assignment uses inferred priority
3.Wrong Category
AI detects incorrect category
Category corrected
Audit log updated
4.Duplicate Ticket
Duplicate detected
Duplicate flag/message shown
Duplicate not assigned twice
5.Vague Ticket
Low confidence returned
Manual review suggested (or appropriate handling)
No over-confident classification
6.Non-English Ticket
Language detected
Text normalized/translated internally
Correct category determined
Correct priority determined
4. Assignment Engine

Assigned only to L1/L2/L3 eligible engineers

Assigned only to L2/L3
High Priority
Assigned only to L3
Least-loaded eligible engineer selected
Capacity respected
Availability respected
